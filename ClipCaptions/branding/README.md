# Clip Captions branding

Logo files, the app icon and store images. The full brand book (colours, type, voice, the caption box) is the Clip Captions design system.

- `clip-captions-lockup-on-light.svg`, `clip-captions-lockup-on-dark.svg`: mark and name.
- `clip-captions-mark-on-light.svg`, `clip-captions-mark-on-dark.svg`, `clip-captions-mark-mono.svg`: the mark alone.
- `clip-captions-wordmark.svg`: the name alone.
- `clip-captions-app-icon.svg`: the app icon (the Android icon in `app/src/main/res/drawable` is drawn from the same shapes).
- `clip-captions-icon-512.png`, `clip-captions-icon-512-square.png`, `clip-captions-banner-1024x500.png`: for store listings.

Colours: night #111733, caption amber #FFC23D, signal blue #2F55D4. Fonts: Unbounded Bold (name and headlines), Atkinson Hyperlegible (everything else).
